# ChemiLab Studio Web

An open-source interactive chemistry platform built with Angular.

ChemiLab Studio provides a dynamic user interface for exploring the periodic table, viewing detailed element properties, and interacting with experimental chemical simulations. The application focuses on usability, visualization, and real-time interaction to enhance the learning experience.

## Tech Stack

- **Angular** 21.2
- **TypeScript** 5.9
- **SCSS** for styling
- **Vitest** for unit testing
- **Node.js** 24.x

## Development

### Prerequisites

- Node.js 24.x
- npm 11.x

### Getting Started

```bash
# Install dependencies
npm install

# Start the development server
npm start
```

Navigate to `http://localhost:4200/`. The application will automatically reload if you change any of the source files.

### Build

```bash
npm run build
```

The build artifacts will be stored in the `dist/` directory.

### Running Tests

```bash
npm test
```
